# Guide

This guide has one page per topic, and each page shows a runnable example of every public name it covers.
Start with values, then ranges, lookup and the vocabularies.

- [Values](values.md): `Unit`, `Quantity`.
- [Ranges](ranges.md): `Range`, `Ranges`, `Role`, `At`.
- [Lookup](lookup.md): `pick`, `Pick`, `Issue`, `IssueCode`.
- [Vocabularies](vocab.md): `Kind` and the condition enums.
- [Worked examples](examples.md): a relay, a contactor with an overload relay, a digital input card.
- [Pins](pins.md): `Pin`, `PinRole`, `Side`, `Link`, `LinkKind`, `Marking`, `contact_pins`, `SupplyInput`.
