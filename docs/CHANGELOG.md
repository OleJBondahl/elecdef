# Changelog

This file holds one section per release of elecdef, newest first.
Every change to the public surface gets a line under Unreleased until the release is cut.

## Unreleased

- Value layer: Unit, Quantity, Range, Ranges, Role, At, pick, Pick, Issue and IssueCode, and the `elecdef.vocab` door with Kind, Current, Utilisation, CoilState and ConductorKind.
- Vocab and leaf blocks: the other vocabularies of `elecdef.vocab`, Connection, Body, Rating and Symbol, and the `elecdef.connections` door with its thirteen technology-only leaves.
- Tables: the `elecdef.tables` door, generated by `scripts/gen_tables.py` from `data/tables/*.toml`: CROSS_SECTIONS, AWG, AWG_METRIC, CORE_COLOURS, BREAKER_CURVES, BREAKER_CURRENTS, BREAKER_ICN, TRIP_TIMES, CABLE_VOLTAGES, OVERVOLTAGE_IMPULSE and E_SERIES.
