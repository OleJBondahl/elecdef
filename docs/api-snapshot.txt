## elecdef
class At(*conds: 'Quantity | Range | Enum') -> 'None'
    The conditions a figure holds under, one per kind, in a canonical order.

class Block() -> 'None'
    The base of every block: it refuses a figure of the wrong kind at construction.

    A caller types a block field, or checks isinstance, against this one class for every block.

class Body(width: 'Quantity | None' = None, height: 'Quantity | None' = None, depth: 'Quantity | None' = None, ip: 'IpCode | None' = None, temperature: 'Ranges' = (), mounting: 'Mounting | None' = None) -> 'None'
    The physical body of a part.

    Temperature rows tell operating (RATED) from storage (LIMITING) by their role.

class Breaker(poles: 'int | None' = None, current: 'Range | None' = None, curve: 'TripCurve | None' = None, icn: 'Range | None' = None, icu: 'Range | None' = None, ics: 'Range | None' = None, rating: 'Rating | None' = None, aux: 'tuple[Contact, ...]' = (), connection: 'Connection | None' = None, body: 'Body | None' = None, symbol: 'Symbol | None' = None) -> 'None'
    A circuit breaker: current, trip curve and breaking capacities, pole pins, auxiliaries.

    Pins and links are computed on every read, so `replace(breaker, poles=1)` leaves none stale.

class Coil(kind: 'CoilKind | None' = None, voltage: 'Ranges' = (), pick_up: 'Range | None' = None, drop_out: 'Range | None' = None, resistance: 'Range | None' = None, power: 'Ranges' = (), apparent_power: 'Ranges' = (), operate_time: 'Range | None' = None, release_time: 'Range | None' = None, suppression: 'Suppression | None' = None, connection: 'Connection | None' = None, own_pins: 'tuple[Pin, ...]' = (), symbol: 'Symbol | None' = None) -> 'None'
    One coil: kind, drive figures, suppression, and the pins computed from kind and suppression.

    `own_pins` holds only pins the author gave; with none, `pins` is A1 and A2 read on every access.

class Connection(technology: 'Technology | None' = None, conductor: 'Ranges' = (), conductor_awg: 'Ranges' = (), conductors_per_clamp: 'int | None' = None, strip_length: 'Quantity | None' = None, torque: 'Range | None' = None, screw: 'ScrewSize | None' = None, pitch: 'Quantity | None' = None, material: 'ConductorMaterial | None' = None) -> 'None'
    One connection point: its technology, conductor range, strip length and torque.

    Every field is unfilled by default, so a leaf states only its technology.

class Contact(form: 'ContactForm | None' = None, features: 'frozenset[ContactFeature]' = <factory>, switching: 'Ranges' = (), voltage: 'Ranges' = (), min_load_voltage: 'Range | None' = None, min_load_current: 'Range | None' = None, material: 'ContactMaterial | None' = None, mechanical_life: 'int | None' = None, electrical_life: 'int | None' = None, connection: 'Connection | None' = None, number: 'int | None' = None, scheme: 'Marking | None' = None, own_pins: 'tuple[Pin, ...]' = (), symbol: 'Symbol | None' = None) -> 'None'
    One contact: form, ratings per condition, and the pins computed from number and scheme.

    `own_pins` holds only what the author gave; `pins` is read from `number` and `scheme` each time.

class ContactBlock(contacts: 'tuple[Contact, ...]' = (), numbered_from: 'int' = 1, actuator: 'ActuatorKind | None' = None, body: 'Body | None' = None, symbol: 'Symbol | None' = None) -> 'None'
    A coil-less carrier of contacts numbered AUX from `numbered_from`.

class Contactor(coil: 'Coil | None' = None, main: 'tuple[Contact, ...]' = (), aux: 'tuple[Contact, ...]' = (), rating: 'Rating | None' = None, body: 'Body | None' = None) -> 'None'
    A contactor: a coil, MAKE main contacts numbered MAIN 1..n, then auxiliaries AUX 1..n.

    A mirror contact is an auxiliary whose features hold `ContactFeature.MIRROR`.

class Device(pins: 'tuple[Pin, ...]' = (), links: 'tuple[Link, ...]' = (), rating: 'Rating | None' = None, connection: 'Connection | None' = None, body: 'Body | None' = None, symbol: 'Symbol | None' = None) -> 'None'
    A thing with no block of its own yet: its pins and links are stored as given.

    Every field is unfilled by default.

class Fuse(system: 'FuseSystem | None' = None, fuse_class: 'FuseClass | None' = None, current: 'Range | None' = None, voltage: 'Ranges' = (), breaking_capacity: 'Ranges' = (), speed: 'FuseSpeed | None' = None, indicator: 'bool' = False, connection: 'Connection | None' = None, symbol: 'Symbol | None' = None) -> 'None'
    A fuse: system, class, current, voltage and breaking capacity, and its two pins.

    The pins are `1` (LINE) and `2` (LOAD), joined by a protective link.

class Issue(code: 'IssueCode', message: 'str', subject: 'str') -> 'None'
    One finding: a code, a message and the subject path it concerns, such as `coil.voltage`.

class IssueCode
    The closed set of issue codes; `check` reports the first eight, `pick` the last two.

class Overload(poles: 'int | None' = None, setting: 'Range | None' = None, trip_class: 'TripClass | None' = None, reset: 'Reset | None' = None, phase_failure: 'bool' = False, aux: 'tuple[Contact, ...]' = (), connection: 'Connection | None' = None, body: 'Body | None' = None, symbol: 'Symbol | None' = None) -> 'None'
    A motor overload relay: main pins per pole, then auxiliaries numbered OVERLOAD.

    Pins and links are computed on every read, so `replace(overload, poles=2)` leaves none stale.

class Pick(found: 'Range | None' = None, issue: 'Issue | None' = None) -> 'None'
    The answer of `pick`: exactly one of the range found or the issue.

class PlcCard(supply: 'SupplyInput | None' = None, groups: 'tuple[ChannelGroup, ...]' = (), form: 'CardForm | None' = None, role: 'CardRole | None' = None, bus: 'Bus | None' = None, sil: 'Sil | None' = None, pl: 'Pl | None' = None, body: 'Body | None' = None) -> 'None'
    A PLC card: supply, groups of channels, form, role, bus and safety levels.

    It stores no pins: `pins` are the supply pins, then each group's channel pins and common pins.

class PowerSupply(kind: 'PsuKind | None' = None, input: 'SupplyInput | None' = None, markings: 'tuple[str, ...]' = ('+', '-'), output_voltage: 'Range | None' = None, output_current: 'Ranges' = (), boost_current: 'Range | None' = None, hold_up: 'Range | None' = None, overload: 'OverloadBehaviour | None' = None, circuit_class: 'CircuitClass | None' = None, isolated: 'bool | None' = None, redundant: 'bool | None' = None, efficiency: 'Ranges' = (), ok_contact: 'Contact | None' = None, connection: 'Connection | None' = None, body: 'Body | None' = None, symbol: 'Symbol | None' = None) -> 'None'
    A power supply: input, output figures and OK contact; the pins are read on every access.

    Outputs: the first PLUS, the second MINUS, a further one PLUS; the OK contact is AUX 1.

class Product(mpn: 'str', manufacturer: 'str', block: 'Block', name: 'str | None' = None) -> 'None'
    A maker's product: part number, manufacturer, optional name and the block it is.

    `check` reports the figures the block's kind needs only for a block inside a Product.

class Quantity(value: 'Decimal', unit: 'Unit') -> 'None'
    A Decimal and its Unit; `==` compares as written, `same` and ordering in base units.

class Range(role: 'Role', *, min: 'Quantity | None' = None, nom: 'Quantity | None' = None, typ: 'Quantity | None' = None, max: 'Quantity | None' = None, at: 'At' = At(items=())) -> 'None'
    A figure as a datasheet states it: a role, up to four ends, and its conditions.

Ranges(iterable=(), /)
    Built-in immutable sequence.

    If no argument is given, the constructor returns an empty tuple.
    If iterable is specified the tuple is initialized from iterable's items.

    If the argument is a tuple, the return value is the same object.

class Rating(voltage: 'Ranges' = (), insulation_voltage: 'Range | None' = None, impulse_voltage: 'Range | None' = None, thermal_current: 'Range | None' = None, frequency: 'Range | None' = None, overvoltage_category: 'OvervoltageCategory | None' = None, pollution_degree: 'PollutionDegree | None' = None, current: 'Ranges' = (), power_loss: 'Range | None' = None) -> 'None'
    A part's ratings: voltages, currents, thermal current, power loss, frequency, clearances.

    Every field is unfilled by default.

class Relay(kind: 'RelayKind | None' = None, coil: 'Coil | None' = None, contacts: 'tuple[Contact, ...]' = (), latching: 'bool' = False, force_guided: 'bool' = False, timer_function: 'TimerFunction | None' = None, body: 'Body | None' = None) -> 'None'
    A relay: a coil and contacts numbered 1..n on every read (the timer scheme for a timer).

    It owns no pin and no symbol of its own, so it has no connection.

class Role
    What a stated figure means: the maker's rating, an extreme withstood, or a reference band.

class Symbol(key: 'str', version: 'int') -> 'None'
    A reference to a drawn symbol by key and version.

    Nothing else of the symbol is held here.

class TerminalBlock(kind: 'LevelKind | None' = None, levels: 'tuple[Level, ...]' = (), sides: 'tuple[Connection, ...]' = (), cross_section: 'Quantity | None' = None, short_time_current: 'Range | None' = None, width: 'Quantity | None' = None, rail: 'Rail | None' = None, rating: 'Rating | None' = None, body: 'Body | None' = None, symbol: 'Symbol | None' = None) -> 'None'
    A terminal block: its levels, the connection on each side and its mounting.

    Pins are computed from the levels on every read.

class Unit
    A unit of one kind with an exact factor to the base unit; `U.V(24)` builds a Quantity.

check(block: 'Block | Product') -> 'tuple[Issue, ...]'
    Report the content issues of a block, or of the block inside a Product, as a tuple.

    A figure a block kind needs is reported only inside a Product; a bare block is a template.

pick(ranges: 'tuple[Range, ...]', *ask: 'Quantity | Range | Enum') -> 'Pick'
    The one range whose conditions cover every ask, else NO_RATING or AMBIGUOUS_RATING.

## elecdef.pins
class Link(markings: 'tuple[str, ...]', kind: 'LinkKind', closed_at_rest: 'bool | None' = None) -> 'None'
    A join between the two pins named by `markings`; `closed_at_rest` is for a switched link.

class LinkKind
    How two pins of a part are joined.

class Marking
    The marking schemes; TIMER and PLAIN are proposed, not sourced.

class Pin(marking: 'str', role: 'PinRole', side: 'Side | None' = None, alternates: 'tuple[str, ...]' = ()) -> 'None'
    One pin: its marking, its role, its side and the alternate markings it may carry.

class PinRole
    What a pin does in its part.

class Pole(line: 'Pin | None', pins: 'tuple[Pin, ...]') -> 'None'
    One pole: every pin its links join, in marking order, and the `line` pin.

class Side
    Which side of a part a pin is on.

class Throw(common: 'Pin', throw: 'Pin', closed_at_rest: 'bool') -> 'None'
    One throw: the `common` pin, the `throw` pin it closes to, and the state at rest.

    `closed_at_rest` is True when the throw is a break pin and False when it is a make pin.

contact_pins(form: 'ContactForm', n: 'int', scheme: 'Marking') -> 'tuple[tuple[Pin, ...], tuple[Link, ...]]'
    Return the pins and links of contact `n` (1 to 9) in `form` under `scheme`.

    Raises TypeError for an `n` out of range or a form the scheme does not have.

poles(pins: 'tuple[Pin, ...]', links: 'tuple[Link, ...]') -> 'tuple[Pole, ...]'
    The poles in marking order: one per run of switched or protective links that share a pin.

    A pin no such link joins is in no pole. A link that names an absent pin is skipped.

throws(pins: 'tuple[Pin, ...]', links: 'tuple[Link, ...]') -> 'tuple[Throw, ...]'
    The switched links that join a COMMON pin to a BREAK or MAKE pin, in marking order.

    A link that names an absent pin is skipped; `check` reports it.

## elecdef.supply
class SupplyInput(voltage: 'Ranges' = (), current: 'Ranges' = (), pins: 'tuple[Pin, ...]' = (Pin(marking='+', role=<PinRole.PLUS: 7>, side=None, alternates=()), Pin(marking='-', role=<PinRole.MINUS: 8>, side=None, alternates=())), connection: 'Connection | None' = None) -> 'None'
    What a powered thing draws: voltage and current per conditions, and its supply pins.

    The pins default to a plus and a minus; a connection is unfilled until a leaf states one.
