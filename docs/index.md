# elecdef

elecdef is a pure Python library of electrical blocks, pins, ratings and product identities.
It is written for every electrical engineer and has no runtime dependencies.

Start with the [guide](guide/index.md). The design is in [DESIGN.md](../DESIGN.md), the rules in [RULES.md](../RULES.md), and the history in [CHANGELOG.md](CHANGELOG.md).
